# Notebooks

Exploration only. The pipeline never imports from here: anything worth keeping moves into `src/falafelona/`.

- Name notebooks `<ws>-<topic>.ipynb`, e.g. `ball-gap-lengths.ipynb`.
- **Clear all outputs before committing** (Kernel → Restart & Clear Output). Outputs can contain real data rows, so the pre-commit hook and CI refuse notebooks with outputs.
- Plots and tables of real tracking stay on your laptop. Share conclusions in words and numbers.
